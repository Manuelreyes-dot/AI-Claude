# AI-Claude

Workspace de experimentos com [Claude Code](https://claude.ai/code) — a CLI oficial da Anthropic para desenvolvimento assistido por IA.

## O que é isso?

Este repositório serve como ambiente de testes e aprendizado com o Claude Code, explorando automações, geração de código e fluxos de trabalho assistidos por IA.

## Como usar

1. Instale o Claude Code: `npm install -g @anthropic-ai/claude-code`
2. Inicie uma sessão: `claude`
3. Explore e experimente!
